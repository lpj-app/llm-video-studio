---
name: new-brand
description: Create a brand with voice rules, CTA phases and a first theme.
---
1. Ask once: name, logo, colors, tone of voice, banned words, CTA phases.
2. `npm run new -- brand <id>`, then edit `brands/<id>/brand.json` (voice, cta) and the theme.
3. `npm run check-contrast` and `npm run validate`.
